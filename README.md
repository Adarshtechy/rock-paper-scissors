# Rock Paper Scissors

A simple and responsive Rock Paper Scissors game built with HTML, CSS, and JavaScript. The game provides a clean interface, score tracking, round history, theme switching, sound controls, and a first-to-3-wins game system.

## Features

- Rock, Paper, and Scissors gameplay
- Computer opponent with random choices
- First player to reach 3 wins becomes the champion
- Real-time score tracking
- Round counter
- Round history
- Win, loss, and draw results
- Game-over popup
- Light and dark theme toggle
- Sound effects with mute/unmute control
- Game rules popup
- Responsive design for desktop, tablet, and mobile
- Clean and simple user interface

## How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer will randomly select its choice.
3. The winner is determined by the following rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
   - Same choices result in a draw
4. The first player to reach **3 wins** wins the game.

## Game Controls
```text
| Control    | Description                            |
| ---------- | -------------------------------------- |
| 🌙 Theme   | Switch between light and dark themes   |
| 🔊 Sound   | Enable or disable game sounds          |
| ❓ Rules    | View the game rules                    |
| Rock       | Select Rock                            |
| Paper      | Select Paper                           |
| Scissors   | Select Scissors                        |
| Play Again | Start a new game after reaching 3 wins |
```
